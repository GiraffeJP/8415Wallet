# 8415wallet V2 Beta 2.0

8415wallet is a general-purpose multichain wallet with existing wallet and asset standards compatibility and native ERC-8415 support. This is the V2 standalone production distribution. The product maturity label is Beta 2.0.

## Capabilities

- Verified wallet login and authentication-method management.
- Owner-controlled agent settings with exact-change verification and durable saved state.
- Per-currency total, unreleased escrow and available funds with exact base-unit arithmetic.
- Indicative USD valuation and commodity reference quotations with explicit source/freshness provenance.
- Ordinary NFT browsing and ERC-8415 projection, temporal query, gap and dual-history reads.
- Source-bound standalone Pending tracks with complete-chain scale, frozen forward milestones and separate coordinated-return evidence.
- Authenticated agent API execution within machine-enforced grants, budgets, nonces and revocation.
- Multichain identity isolation and wrong-chain refusal.

## Install

Read `docs/V2-INSTALL.md`. Verify the archive with the independent SHA-256, source-tree and simulation-receipt pins before extraction. The distribution is generic: the recipient supplies tenant, origin, listener, storage and provider configuration. No deployment or service activation is performed by the package.

## Validation

This distribution is pinned to a successful controlled Linux simulated acceptance receipt (`SIMULATION-RECEIPT.json`). That receipt is synthetic-port source validation, not a security audit, live deployment, real mail/hardware success or on-chain acceptance.
