# 8415wallet V2 product boundary

This distribution delivers the V2 standalone capability profile. It does not deliver the linked responsibility profile, native platform applications, a private provider implementation, production credentials or a configured tenant instance.

## Recipient configuration

The recipient configures tenant identity, expected origin, listener/socket, encrypted store path, mail transport, CA trust material, read sources and any external provider composition through the protected installers and trusted runtime configuration. The generic template uses the default tenant and an unconfigured endpoint until the recipient supplies those bindings.

## Security and reconciliation

Login is not transaction authority. Agent operations remain bound to principal, account, chain, task, assets, fees, expiry and revocation. Owner-saved OFF removes repeated in-scope human verification but does not remove machine-enforced scope, nonce, budget or UNKNOWN reconciliation. Uncertain submitted operations are never blindly resent.

## Evidence

The public simulation receipt records controlled Linux synthetic-port validation for the retained acceptance contract. Live deployment, real mail, hardware devices, physical browsers, independent security audit and on-chain acceptance are separate evidence levels and are not asserted by this distribution.
